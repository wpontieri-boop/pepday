==================================================
4. CALCULADORA
==================================================

Preservar a calculadora existente.

Entradas:
- mg do frasco
- água bacteriostática em mL
- quantidade desejada em mg ou mcg
- seringa U-100: 30 / 50 / 100 UI

Cálculos:

concentração = mg do frasco / mL de água

se dose em mcg:
dose_mg = mcg / 1000

volume_ml = dose_mg / concentração

UI = volume_ml × 100

Manter bloqueio/aviso caso UI calculada ultrapasse a capacidade da seringa.

Escalas aprovadas:
30 UI e 50 UI:
1 UI por traço pequeno, números a cada 5.

100 UI:
2 UI por traço pequeno, números a cada 10.

NÃO alterar o desenho aprovado das seringas sem necessidade.

==================================================

IMPORTANTE:

Ao clicar em “Cadastrar novo frasco”:

1. preservar todos os dados já digitados na rotina;
2. abrir cadastro de frasco;
3. cadastrar nome/fármaco, mg, água/mL, data etc.;
4. salvar;
5. retornar AUTOMATICAMENTE para Nova Rotina;
6. selecionar automaticamente o frasco recém-criado;
7. restaurar os demais campos da rotina;
8. permitir concluir a rotina.

O usuário NÃO deve precisar abandonar a rotina para cadastrar o frasco.

- nome
- mg
- mL

Salvar frasco → voltar para rotina → frasco selecionado.

Fluxo conceitual:
